# BassStation 自动扒谱架构方案（v2）

## 0. 现状与根因

| 指标（全曲、严格时间对位） | 旧引擎原始音符 | 旧引擎最终 GP |
|---|---|---|
| 音高准确率 | 44.3% | 3.2% |
| 起音召回 | 63.0% | 44.9% |
| 时值准确率 | 30.5% | 20.8% |

根因不在某个参数，而在架构：
1. **没有学习**：CQT/HPS/PYIN 手工规则，无法利用曲库里 313 首带音频+同步点的正版谱。
2. **小节网格按恒定速度切分**：任何速度波动都会一路漂移，最终 GP 几乎全部错位。
3. **各环节各自为政**：分离、音高、节拍、量化、指法互不校验，错误逐级放大。
4. **没有可信的评测**：旧指标（18 秒片段 + 序列匹配）看不到时间错位。

## 1. 已完成的基础设施（本轮前后）

- `bassnet/gpif_parser.py`：GP6/7/8 解析，展开反复，SyncPoint→音频时间（语义已实测验证）。
- `bassnet/dataset.py`：音高感知互相关 + 分段精调，把 GP 标签对齐到分离后的贝斯音轨，命中率 96–100%。
- `bassnet/quantize.py` + `gp_writer.py`：节拍网格量化（逐拍选 16 分/三连/复合拍，逐小节变拍号），逐小节同步点。回环保真度：音高 99.7%、时值 99.3%。
- `bassnet/score_align.py`：任意录音版本 ↔ 乐谱对齐（粗 DTW → 小节 Viterbi → 11.6ms 带状 DTW），音符中位误差 0–44ms，带音高特异性质量门控。
- `bassnet/score_eval.py`：乐谱级评测（音高 / 起音 / 时值 / 整音符正确率）。
- `gp_guard.py`：原版谱写保护。

## 2. 目标架构

```
原曲 ──► ① 分离集成 ──► ② 声学模型 ──► ③ 节拍/拍号 ──► ④ 联合解码 ──► ⑤ 记谱与指法 ──► GP
             │              ▲   ▲            ▲               ▲   ▲             │
             │              │   └──混音分支──┘               │   └ 乐句重复一致性
             └── 残差/置信度 ┘                 记谱语言模型（340 份谱训练）┘
                                                                          ▼
                                                           ⑥ 置信度标注 + 人工校对回流训练
```

### ① 分离：多模型集成 + 测试时增广
- BS-Roformer-SW（overlap 8）+ 贝斯专用 Mel-Roformer + htdemucs_ft，频带加权融合。
- 声学模型同时输入"分离音轨 + 原混音"，由模型自己补回分离丢掉的低 B 基频、被鼓掩盖的音头。

### ② 声学模型 BassNet（已实现 v1，待训练）
- 谐波 CQT（½f…6f 对齐基频）+ 卷积 + 双向 GRU；输出：单音音高（49 类）、起音、闷音、拍、强拍。
- **标签自对齐（EM）**：用模型输出反过来对训练标签做 DTW 精修再训练，消除 GP 同步点的毫秒级误差（Maman & Bermano 2022 思路）。
- 扩展头：滑音、击勾弦、Slap/Pop、泛音（GP 标签里都有）。
- 进阶实验：以预训练音乐基础模型（MERT 等）特征作为补充输入。

### ③ 节拍/拍号
- 与声学模型联合训练（已实现）；DP 解码允许速度突变、逐小节强拍（已实现）。
- 速度层级（记成 90 还是 180）交给④的记谱语言模型裁决，贴合谱面惯例。

### ④ 联合解码（本方案核心，避免"逐帧取最大值"的局部最优）
- **记谱语言模型**：用 340 份正版贝斯谱（加移调增广）训练小型 Transformer，学习"合理的贝斯乐句"：根音八分、经过音、切分习惯等。
- **束搜索解码**：分数 = 声学似然 + λ·语言模型先验 + 节拍网格对齐分，像语音识别中的声学模型 + 语言模型组合。
- **乐句重复一致性**：用自相似矩阵找出重复段落（主歌/副歌），对应小节做加权投票。单次出现的随机错误会被多次重复纠正。这是向 100% 逼近的关键杠杆。

### ⑤ 记谱与指法
- 量化器已无损；时值使用模型预测的"记谱时值"，而非声学衰减。
- **学习式指法**：用 340 份谱里人类扒谱者的弦/品选择训练分类器，替代手工代价函数，使输出的 TAB 与熟练扒谱者的习惯一致。
- 调弦识别：音高直方图 + 音分偏差（降半音、Drop D、五弦）。

### ⑥ 置信度与人工闭环
- 低置信度小节在 GP 里用文字标记/颜色标出，只需检查少数小节。
- 你修正后的谱自动加入训练集（主动学习），模型在你的曲库风格上持续变好。

### ⑦ 演奏评测重建（修复遗留问题）
- 现有评测不看乐谱、不看音高，分数被限制在 60–99，结果不可信。
- 重建：录音 → ②③ → 与 GP 逐音符对齐（score_align）→ 按小节给出音准、节奏偏差（ms）、时值、漏音和错音。

## 3. 实施阶段（需占用 GPU，按你的空闲时间执行）

| 阶段 | 内容 | GPU 时长（估） | 验收指标 |
|---|---|---|---|
| P1 | 完成 291 首分离；训练 BassNet v1；EM 标签精修 | 约 4.5h + 2h | 留出集 音高准确率、时值准确率（对比基线 44%/31%） |
| P2 | 记谱语言模型 + 束搜索；重复一致性投票；学习式指法 | 约 2h | 整音符正确率提升；TAB 与原谱指法一致率 |
| P3 | 分离集成 + 混音重组增广 + 合成数据；技巧头 | 约 6h | 困难曲（五弦、失真、Live）单独报告 |
| P4 | 置信度标注、校对回流；演奏评测重建 | 约 1h | 评测结果与人工判断一致 |

所有阶段统一在留出测试集（按歌名分组，防泄漏）上报告同一套指标，任何改动都必须带回归对比。

## 4. 实施进展（2026-09-26）

### 已完成
- 全库 296 段音频的贝斯分离与特征构建；标签质量门控后可用约 280 首。
- BassNet v1（CQT + 混音 mel，双向 GRU）、v2（新增分离音轨宽频分支、EM 标签精修）。
- 数据修正：
  1. 同一音频有 4 弦/5 弦两份谱时，原先误选了 4 弦改编版（低音被移高八度）→ 改为优先 5 弦完整版（涉及 19 首 Ave Mujica 等）。
  2. 首轮标签对齐基于 CQT 能量，低音区时间模糊严重（部分歌偏差 >100ms）→ 改为短窗 STFT 起音包络 + 音高能量联合对齐，全局偏移中位 25ms，15% 的歌原偏差超过 50ms。
- 解码调参（验证集）：起音阈值 0.5、音高判定窗口后移到起音后 2–10 帧（起音匹配时音高准确率 85%→90%）。

### 测试集结果（35 首从未参与训练的歌，最终 GP 与原谱逐音符比对）
| 指标 | 旧引擎 GP | BassNet（v1/v2 集成，标签修正后） |
|---|---|---|
| 音高准确率 | 3.2% | 71–73% |
| 起音召回 | 44.9% | 82–84% |
| 时值准确率 | 20.8% | 84–85% |
| 全对（音高+位置+时值） | 0.8% | 61–63% |

### 经验证无效（已关闭）
- 重复段落一致性投票：受控测试有效（74%→96%），真实后验上 −3%（节拍/后验不够干净时投票会互相污染）。
- 音程语言模型重打分：受控测试有效，真实数据上无增益（双向 GRU 已隐式学到乐句上下文）。
- 放宽连奏合并容差：时值准确率下降。

### 剩余误差构成（给定真实起音时的音高判断）
- 八度错误占比最大：主要来自 4 弦移调标签的遗留影响（v3 用修正数据重训）与合成贝斯八度叠加的编曲。
- 半音/其他错误分散，无系统性调弦问题。
- 起音召回约 79–84%：同音重复拨弦是最大漏检来源。

- v3：修正后的全部标签 + 新结构，70 轮。
- 之后：更强的时序模型（Conformer）、分离模型集成、针对同音重复的起音头改进。
