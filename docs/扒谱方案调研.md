# 自动扒谱方案调研（2026-09-26）

## 1. 各方案实现方式

| 方案 | 类型 | 核心做法 | 输出 | 许可 |
|---|---|---|---|---|
| To-Sheet-Music-Skill (kiri603) | Claude Agent Skill | Demucs 分离（4/6 轨对照）→ 可选 Basic Pitch 取候选音符 → **按难度改编**成五人乐队谱（不是忠实扒谱）→ MusicXML → MuseScore 导出；`score_tools.py audit` 做结构/TAB 合法性检查后才发布 | MIDI / PDF / MSCZ | 代码 MIT |
| sheetsage2-webui (3253473591) | 工程封装（未训练模型） | 调用 M-A-P **SheetSage2**：MERT-v2-FullSong 音乐基础模型 + 任务适配器；输出旋律（人声/器乐）、和弦、节拍/强拍、调性、段落；网页钢琴卷帘编辑 | MIDI / ABC / SynthV | 权重 CC BY-NC 4.0 |
| SheetSage（原版，Donahue 2022） | 研究 | Jukebox 生成模型的特征 → **按 madmom 节拍对齐到十六分音符网格（每拍 4 格，取平均）** → Transformer 逐格预测"起音+音高/无"；直接得到乐谱，无需事后量化；基础模型特征相对频谱 +20% | 旋律+和弦 lead sheet | CC BY-NC-SA |
| Songsterr AI Transcribe | 商业 | 未公开；按分轨出吉他/贝斯/鼓/人声草稿，**必须人工检查后才发布**，在编辑器里改音 | Songsterr 谱 | 商业 |
| Klangio / Songscription | 商业 | 分离 + 单乐器转录 + 编辑器；可导 GP/MusicXML | GP / MusicXML / MIDI | 商业 |
| YourMT3+（2024）/ MuScriptor（2026） | 研究 | 多乐器 token 式 Transformer（MT3 路线），含 Bass 类；MuScriptor 1.3B，合成 145 万 MIDI + 17 万真实录音 + RL | 演奏 MIDI（无记谱） | YourMT3 开源；MuScriptor 权重 CC BY-NC |
| TART（ISMIR 2026） | 研究（吉他） | 四段式：CRNN 转 MIDI → **逐音符技法分类器**（音符时长窗口的 MFCC+mel+chroma → CNN-BiLSTM，9 类技法，干净数据集上 F1 95.9%）→ 音频条件的 T5 分配弦/品 → 生成 tab；端到端 Tab F1 54% | Tab | 研究 |
| Fretting-Transformer / MIDI-to-Tab | 研究（吉他） | 符号序列 → 弦/品 序列（T5 / 掩码语言模型） | Tab | 研究 |

贝斯专用：近年没有深度学习的贝斯 tab 论文；老工作（Fraunhofer IDMT，Abeßer）用手工特征 + SVM 做弦/品/技法估计；数据集 IDMT-SMT-Bass（约 4300 个单音，10 种技法：指弹、拨片、闷音、Slap 拇指/勾弦、揉弦、推弦、泛音、死音）。

## 2. 共同的失败模式（评测与用户反馈）
- 节奏/量化最弱：整段错位一个八分音符或两拍、长音被切成两个、单音被识别成快速双击（Songscription 官方指南原话）。
- 贝斯八度误判（按吉他音域时低一个八度）。
- 指法把位无故跳动（Songsterr 用户反馈）。
- 技法（滑音、闷音、ghost note）普遍捕捉不到（TART 作者："current transcription systems capture none of them"）。
- 所有商业产品都定位为"草稿 + 人工编辑"。

→ 我们遇到的问题（多拆同音、节奏写法、八度、指法、技法）是行业共性，没有现成方案能直接解决贝斯记谱。

## 3. 与本项目对比
- 我们的优势：用 300 份与录音对齐的购买原谱做监督（同风格、贝斯专用、带记谱信息），这是通用工具没有的。声学层（音高约 80%、起音约 90%）已不弱。
- 我们的短板正是 SheetSage 解决的问题：**音符→记谱**靠手写量化规则。

## 4. 可借鉴、按预期收益排序
1. **节拍同步预测（SheetSage 思路）**：在我们的节拍网格上把特征池化到每拍 12 格（兼容十六分与三连音），直接以原谱 qpos/qdur 为标签预测"每格：新音起音 / 延续 / 休止 + 音高"。直接学习扒谱者对重复音、时值的写法，替代手写量化。数据现成。
2. **音乐基础模型特征**：Jukebox→MERT/MusicFM 在旋律和多乐器转录上都有明显提升；可把 MERT 特征作为新分支输入（MERT 权重 CC BY-NC，个人自用合法；约 1.2 GB）。针对八度/音色鲁棒性。
3. **和弦先验**：SheetSage2 的和弦识别（osu2017 90%）可作为贝斯音高解码的先验（根音、和弦音），针对半音/四五度错误。
4. **YourMT3+ 贝斯轨做基准/集成**：先在我们的测试集上测其贝斯音高准确率，若有互补则集成或作伪标签。
5. **技法**：学 TART 做逐音符分类器（整音符窗口，而非起音帧），滑音另用音高滑移信号检测；Slap/闷音/泛音可引入 IDMT-SMT-Bass（需查许可）。
6. **人工校对闭环**：所有商业方案都靠编辑器；我们的"核对版"修正应回流为高权重训练数据。
7. **导出前审计门**（To-Sheet-Music-Skill 的 audit、我们的 gp_lint + GP8 实机截图）——已做。
