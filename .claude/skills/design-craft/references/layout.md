# 版：构图、网格、关系

## 1. 网格与轴线

- **先定网格，再放东西。**
  - 界面用 8px 基准（细处用 4px），正文按基线网格排；
  - 列网格常用 12 列或 6 列；游戏或海报类可以用少量粗列，加一条斜轴。
- **每个元素都要说得出位置理由。** 它和谁对齐？它压着谁？它离谁多远，为什么是这个距离？
- **轴线少而强。** 一屏 2–4 条主轴线，比如左边线、主内容的上边线、底线、一条斜轴。并列模块要共用顶线或底线。
- **间距成体系。** 组内距小于组间距小于区块间距，比如 8 / 16 / 32 / 48。差距要明显，不要 14、16、18 这样混着用。

## 2. 格式塔：模块之间怎么建立关系

| 原理 | 用法 |
|---|---|
| 邻近 | 靠得近就是一组，比加框好 |
| 相似 | 同色、同形、同字号就是同一类 |
| 共同区域 | 色面或底板圈起来就是一组。这是框的正当用途，要少用 |
| 连续 | 沿一条线或轨道排列的元素会被读成一条序列 |
| 闭合 | 不画完的形也能被看全，可以省线 |
| 图底 | 主体和背景要分得开，图底能互换的视觉趣味要慎用 |
| 共同命运 | 一起动、一起变色，就会被读成一体 |

## 3. 视觉重量与平衡

- **决定视觉重量的因素：** 面积大、颜色深、饱和度高、形状复杂、离中心远、在上方、带人脸或文字，都会更重。
- **非对称平衡比对称更有活力。** 一个大而轻的形，可以平衡一个小而重的形。
- **对角平衡。** 两个强元素分在对角，比如左上的主题面和右下的主键，画面就有一条张力线。
- **重力。** 重的、深的东西放在下面或左边，画面就稳；倒过来也可以，但必须是有意为之。

## 4. 阅读路径与焦点

- **单一焦点。** 最大、最亮或最饱和、明度对比最强的地方就是第一眼。
- **阅读顺序。** Z 形适合海报、结算页这类稀疏画面，F 形适合列表这类密集画面。信息按顺序落在路径上。
- **先总览，再细节。** 用户先要整体印象：总分、全局分布。再按需深入：选中某一段，看细节。总览和细节要有可见的连接，比如楔形、连线、同色高亮。

## 5. 遮挡与层次

- **前中后三层。**
  - 背景：插画或色面；
  - 承托：纸、板、墨块；
  - 前景：数字、主键、徽章。
  - 层次靠遮挡、投影和明度来建立。
- **遮挡要有语义。** A 压着 B，就表示 A 属于 B、A 是从 B 上取出来的，或者 A 被贴在 B 上。没有语义的遮挡显得乱；完全没有遮挡显得飘。
- **出血。** 色面或图片延伸出屏幕边，画面会更大、更稳。悬浮在中间的方块就是"卡片味"。
- **每屏遮挡 1–3 处就够了。**

## 6. 少用框

- **框是最后才用的手段。** 先试这几种：
  - 留白分组；
  - 一条线；
  - 色面或明度差；
  - 字号层级；
  - 对齐。
- **非用框不可时：**
  - 框的形状和圆角要分档：结构类方一些，触点类圆一些；
  - 嵌套时内圆角等于外圆角减去间距；
  - 同一屏的框不要全部同一个样子。
- **"倒角方框堆砌"是 AI 味的典型。** 卡片网格、每个模块都装在一个圆角盒里，都属于这一类。

## 7. 留白与密度

- **留白要主动留。** 它应该是一块形状，比如插画露出来的部分，或者一整块干净的纸面，而不是元素之间平均分剩下的缝。
- **密度跟着任务走。**
  - 工具屏（谱面、表格、编辑器）可以密，但要成组、有节奏；
  - 展示屏（结算页、首页）要疏，焦点要大。
- **数据墨水比（Tufte）。** 删掉不承载数据的线、框、底纹、3D 效果。小倍数（同构的小图并排）比一张复杂的大图好读。
- **版面率。** 被内容和图形占满的面积比例。高显得热闹、有张力；低显得高级、安静。也要和产品性格一致。

## 8. 常用构图骨架

| 骨架 | 结构 | 适合 |
|---|---|---|
| 三栏 | 左列表或导航（重块）→ 中主体 → 右详情加主动作 | 选择、浏览 |
| 主题面加承托纸 | 斜切色面放结论数字，纸面放细节，满色图露在一侧，主键在对角 | 结算、报告 |
| 主角大图加表格板 | 角色或图片占一半以上，一块干净的板放数据，主键在板下 | 结果、详情 |
| 文档加底栏 | 大面积纸放内容，底部深色栏放走带或工具，进度条在栏的顶边 | 阅读、播放工具 |
| 总览带加细节区 | 顶部一条全局缩略带，选中部分用楔形连到下方细节 | 时间线、长数据 |

## 9. 检查办法

- **模糊测试：** 看大形和焦点。
- **灰度测试：** 看层级在没有颜色时是否还成立。
- **翻转或倒置：** 看平衡，倒过来更容易看出偏沉。
- **缩到 25%：** 看还能不能一眼认出是哪个产品。
