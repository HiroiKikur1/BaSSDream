# 音乐类画面：节拍、歌词、播放

标杆：millsage 的两首歌的节拍/歌词可视化（用户给的截图，BaSSDream 里在 `design-lab/refs/millsage/`）。同一支乐队、两套完全不同的视觉，因为各自从那首歌的素材里长出来。

## 1. 让那首歌自己成为设计源

- **配色从曲绘或场景里取。** 《鳴らす》的淡紫、鼠尾草绿、浅粉取自封面，角落水彩色晕也是这几色；《everscape》的桃粉、橙、暗梅紫取自像素黄昏场景，信息面板的底色是房屋阴影的暗梅紫，不是通用半透明黑。工具：`tools/palette.py`。
- **母题从素材延伸出去。** 封面是拼贴碎片 → 封面背后错开垫几块同色系纸片色块；场景是像素画 → 拍格是像素方块、数字是像素字、面板是直角。
- **字体从标识里来。** logo 是衬线手写感 → 标题用衬线，副信息用斜体衬线（像唱片内页署名），日文歌词用明朝。
- **一个画面只有一种媒介。** 像素场景上的面板也是像素的；印刷感的画面里没有圆角卡片和投影。前景和背景画法不同，前景就会浮起来。
- **品牌记号兼任功能。** millsage 的花形记号同时是 logo、进度条滑块、表盘上第一拍、时间轴上每个强拍的标记。不要另画一个通用圆点当滑块。
- **文化原型：CD 封套。** 右侧竖排“millsage — 鳴らす”像腰封或书脊，底部“1st Single — 鳴らす · Full ver.”像内页署名。原型给了每个小元素一个来历。

## 2. 音乐信息的版式

- **用记号，不用“标签 + 数字”。** 拍号竖排成分数（3 / 横线 / 4）；速度写 ♩=184；节拍分组 3+3+3 用拍格之间的空隙表现。记号说清了，就不再加标签。
- **当前大，总量小。** `36 / 168`、`00:46 / 03:49`：当前值大字，总量与单位小一号、浅一级，同一基线。剩余时间写 `-03:16`。
- **两个尺度同时在场。** 局部（这一小节的拍格或表盘，当前拍实心）+ 全曲（时间轴按拍号或段落着色，强拍有记号），一根播放头连起来。过去压暗，未来清楚。
- **提前预告变化。** 下一个拍号、速度、段落在到来前显示，写明距离（“7/4 · 12 小节后”），用未到达的浅色。
- **不用框子分层级。** 歌词页没有一张卡片：当前行最大最深，左侧一根细竖线标记，翻译小一号紧贴其下，离当前行越远越淡；当前行逐字填色。
- **拍点要精确。** 拍点数等于分子、等距；第一拍有独特记号；分组拍（7/8 = 2+2+3）按组留空。
- **只让信息动。** 动的是当前拍、播放头、逐字填色，并且对齐节拍；背景静止。

## 3. 标杆的缺点（不学）

- 英文小标签：METER / TEMPO / BAR / NEXT / OF 3 / QUARTER。
- 同一视口里“3”“OF 3”“3/4”把同一件事说了三遍。
- 预告信息（NEXT 7/4）太浅。演奏者离屏幕一两米：淡只能降一级，不能淡到读不出；演奏时要看的数按远距离可读的字号定。
- 明暗：歌词页和节拍页是高调画面（亮部约 94%），骨架靠封面那块满色中间调和一个深紫大字。去掉封面，这种画面会立刻变“软”。高调画面必须有一个强焦点来撑。
