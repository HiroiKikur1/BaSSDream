# 游戏 UI 与"游戏感"界面

## 1. 世界观整合

- **画面上的一切都在表达世界观。** UI 是世界的一部分，不是浮在世界上的工具栏。
- **先有概念和世界，再有界面。** 界面的材质、字体、形状都从世界里取。比如：
  - 怪盗世界：剪报、红黑白；
  - 机械世界：工业标识、网格；
  - 乐队世界：谱、弦、排练室。
- **母题可以藏在细节里。** 比如 NieR 的乐谱母题、P5 的手机和手账母题。
- **视觉为功能服务，也影响功能。** 例如角色进入觉醒状态时，血条一起变形，用一点响应性换取情绪。

## 2. 结算页

- **主角和数据分开。** 角色或插画用满色，占一半以上的画面；数据放在一块干净的板上。
- **信息分层：** 分数、评级、判定计数放在第一层；详细数据收起来，按需展开。
- **一个仪式：** 数字滚动、评级落定、全连标出现。不要满屏粒子。
- **一个主动作：** "下一步"或"再来"用大号主色键；分享这类次要动作用白键。
- **判定计数：** 判定字用固定的颜色约定，计数用等宽字，前导零做淡，FAST / SLOW 这类细分放成小标签。

## 3. 选中语法与可按的东西

- **选中要打破边界。** 选中项变大、溢出列宽、换成主题色。未选中项安静、统一。
- **按钮要有物感：** 顶光、厚度、按下时下沉。主键只有一个，大号、主题色。
- **列表行：** 深色条配浅色字可以形成重块，节奏统一，信息右对齐。

## 4. 能量与角度

- **斜线和斜切带来动感。** 全局只用一个角度，最好来自 Logo。
- **出血的色带、斜切面、超大数字** 是游戏 UI 区别于后台系统的主要手段。

## 5. 标杆拆解（记的是可观察锚点）

| 作品 | 锚点 |
|---|---|
| 明日方舟 | 右侧透视倾斜的白色功能块群，左侧是角色；巨号数字配中文，再配极小的英文；工业标识风；换皮肤只换配色和背景，几何不变 |
| 终末地 | 粗黄弧带承载技能节点，角色站在带上；浅灰网格地；Logo 衍生的图形渗进面板 |
| 少女乐团派对（ガルパ） | 白、灰、粉三色克制；深灰歌单条配粉色溢出选中条；粉压白的叠层标题牌；评级星分黄、粉、彩三级；结算页是满色立绘配白板、粉色"下一步"；前导零计数；描边判定字 |
| BanG Dream! Our Notes | 手写体 Logo 加笔刷；幻彩边框；斜切标题带加乐队 Logo 徽章；笔记本母题 |
| Persona 5 | 只用红、黑、白；剪报字；斜线排列；选中项变大；操作提示缩在右下 |
| Splatoon | 墨水和街头运动；结果页用姿势表现；包装挂钩做子母题 |
| NieR: Automata | 极简米灰，以乐谱为隐性母题 |

## 6. 共同规律

- 贯穿全屏的结构性手势本身就是信息。
- 结构性手势来自世界里的实物。
- 主体和 UI 互相遮挡。
- 一屏只有一个最大的数字或标题。
- 换皮肤只换颜料，不换几何。
- 文字少，图形和数字多。
